# Temporal Money Transfer Project (Rust)

> **Status:** Work in progress. This sample is not yet ready for use.

A sample application that demonstrates a money transfer between two accounts using
[Temporal](https://temporal.io) and the Temporal Rust SDK. It shows how a Workflow
coordinates Activities (withdraw, deposit, refund) and how Temporal handles retries,
failures, and compensation so the transfer completes reliably.

## Prerequisites

- [Rust](https://www.rust-lang.org/tools/install) (stable toolchain)
- [Temporal CLI](https://docs.temporal.io/cli) for running a local development server
